# 2. Personas

Três personas, uma para cada grupo que os bancos atuais atendem mal: baixa leitura, menor de idade e idoso. Cada uma aponta para funcionalidades do Documento de Visão (F01 a F16).

## Antônio, 47 anos

| | |
| --- | --- |
| Profissão | Ajudante de pedreiro, recebe por diária |
| Escolaridade | Estudou até o 5º ano. Lê com dificuldade |
| Celular | Android de entrada, usa WhatsApp e áudio |
| Como lida com dinheiro hoje | Recebe em dinheiro vivo ou pelo cartão de um parente |
| O que já deu errado | Foi enganado por um golpista que se passou por atendente do banco |
| Dores | Tem vergonha de pedir ajuda. Textos longos o fazem desistir. Depende de outra pessoa para receber o próprio pagamento |
| Motivação | Ter uma conta própria que consiga usar por ícones, áudio e poucos passos, sem depender de ler textos longos nem de ninguém |
| O que o Rufus entrega | Abertura guiada por voz (F01), receber diária por QR Code (F05), saldo falado (F03), confirmação falada antes do Pix (F04), aviso de que o Rufus nunca liga (F11) |

> "Eu só quero ver quanto eu tenho e mandar pro mercado sem pedir pra ninguém ler pra mim."

## Camila, 17 anos

| | |
| --- | --- |
| Profissão | Estudante do ensino médio e jovem aprendiz (contrato da Lei 10.097/2000) |
| Renda | Um salário pequeno de aprendiz |
| Celular | Usa bem, nativa digital |
| Objetivo | Juntar dinheiro para comprar um notebook |
| Situação legal | Menor de 16 a 18 anos precisa ser assistida pelos pais para atos da vida civil, como abrir conta |
| Dores | Os bancos atuais ou bloqueiam a conta dela ou a tratam como adulta, sem nenhuma educação financeira. Os pais precisam autorizar tudo |
| Motivação | Ter autonomia dentro de limites seguros, com conta vinculada ao responsável e metas de economia fáceis de entender |
| O que o Rufus entrega | Conta de menor vinculada (F07), limites e pedidos de aprovação ao responsável (F08), meta "notebook" com progresso em imagem (F09), dicas curtas em áudio (F13) |

> "Eu quero decidir o que fazer com o meu dinheiro, mas sem meus pais terem que aprovar cada lanche."

## Dona Marlene, 68 anos

| | |
| --- | --- |
| Profissão | Aposentada |
| Celular | Usa só para WhatsApp |
| Como lida com o banco hoje | Depende do neto para mexer no app do banco |
| Dores | Tem medo de errar e perder dinheiro. Letra pequena e muitos menus confundem. Tem medo de golpe por telefone |
| Motivação | Ter autonomia para pagar as próprias contas sem pedir ajuda |
| O que o Rufus entrega | Pagar conta apontando a câmera (F06), lembrete de conta a vencer (F12), neto como contato de confiança (F10), botão "bloquear tudo agora" (F11), atendimento humano só pelo app (F14) |

> "Eu pago minhas contas desde sempre. Só não quero ter que esperar meu neto ter tempo."

## Como as personas viram requisito

As dores das três personas se repetem em quatro pontos, e cada ponto vira um requisito não funcional com número no Bloco 2:

| Dor em comum | Personas | Vira no Bloco 2 |
| --- | --- | --- |
| Ler com dificuldade | Antônio, Dona Marlene | Toda tela com leitura em voz alta e texto em nível de leitura simples |
| Medo de errar | Dona Marlene, Antônio | Confirmação antes de mover dinheiro e desfazer enquanto não confirmado |
| Medo de golpe | Antônio, Dona Marlene | Regras antifraude e contato de confiança |
| Autonomia com limite | Camila, Dona Marlene | Papéis de responsável e de contato de confiança com permissões diferentes |
