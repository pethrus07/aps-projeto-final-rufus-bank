# App mobile (React Native com Expo)

Criado na primeira tarefa do Sprint 1 (`bloco-8-dev/06-sprint-1.md`), com:

```
npx create-expo-app@latest . --template blank-typescript
```

Decisão e motivos: ADR-005. Bibliotecas previstas: expo-secure-store, expo-local-authentication, expo-camera, expo-av (áudio), cliente da API gerado de `bloco-8-dev/openapi.yaml`.

Regras que valem desde a primeira tela (RNF08 e RNF09): botão "Ouvir" em toda tela, área de toque de 48 dp, texto base de 18 sp, contraste de 4,5:1, teste com TalkBack e VoiceOver.
